# 🍽️ Multi-Restaurant Booking Platform

A full-stack web app that lets customers book tables at restaurants online. It also gives restaurant owners and admins their own dashboards to manage everything easily.

## 📖 About This Project

This project is a complete booking system for restaurants. Customers can search for restaurants and book a table. Restaurant owners can manage their tables and see bookings. Admins can control the whole platform.

It is built using the MERN stack, which means MongoDB, Express.js, React.js, and Node.js.

## 🛠 Technologies Used

- **React.js** – for building the user interface
- **Node.js** – for running the backend server
- **Express.js** – for creating REST APIs
- **MongoDB** – for storing all the data
- **MERN Stack** – React, Node, Express, and MongoDB together
- **JWT Authentication** – for secure login and user sessions
- **REST APIs** – for connecting the frontend and backend

## 👥 Who Can Use This App?

There are three types of users:

1. **Customers** – can search restaurants, check tables, and book a reservation
2. **Restaurant Owners** – can register their restaurant, manage tables, and see bookings
3. **Admins** – can manage all restaurants and users on the platform

## 🔑 Key Features

- Secure login and signup with JWT
- Role-based access, so each user only sees what they need
- Restaurant owners can add and manage tables
- Customers can easily book a table in a few clicks
- Admin panel to control the whole platform
- Fully responsive design that works on mobile and desktop
- Clean and simple REST API structure

## 📂 How the Project is Organized

- **Frontend:** Built with React.js and Tailwind CSS for a smooth and responsive design
- **Backend:** Built with Node.js and Express.js to handle all the logic
- **Database:** MongoDB stores restaurants, tables, bookings, and user data

## 🚀 How to Run This Project Locally

1. Clone this repository
```bash
git clone https://github.com/Sushmita-2701/booking-platform.git
```

2. Go into the project folder
```bash
cd booking-platform
```

3. Install the backend dependencies
```bash
cd backend
npm install
```

4. Install the frontend dependencies
```bash
cd ../frontend
npm install
```

5. Add your environment variables (like MongoDB URL and JWT secret) in a `.env` file

6. Run the backend server
```bash
npm start
```

7. Run the frontend app
```bash
npm run dev
```

8. Open your browser and go to `http://localhost:3000` (or whatever port your app uses)
